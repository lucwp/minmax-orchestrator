# Repository Maintenance Rules

## README synchronization is mandatory

Every repository update must include an explicit README review before it is considered complete.

When a change affects public behavior, model support, release names, stable distributions, usage, compatibility, installation, capabilities, limitations, or project status, update `README.md` in the same change. Do not merge or publish a user-visible repository change with a stale README.

For maintenance-only changes with no user-visible effect, still verify that the README remains accurate. The README must remain fully client-facing: document only what a user needs to understand, choose, install, or use the project; do not expose private environment details, internal conversation context, temporary migration mechanics, or maintainer-only implementation history.
